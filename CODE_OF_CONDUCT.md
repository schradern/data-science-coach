# Verhaltenskodex

Dieses Projekt soll ein respektvoller, sachlicher Ort für alle sein – unabhängig
von Erfahrung, Fachrichtung, Herkunft oder Identität.

**Erwünscht:** sachliche Kritik, hilfreiche Korrekturen, Geduld mit Einsteiger:innen.

**Nicht toleriert:** Beleidigungen, Belästigung, Herabwürdigung, Off-Topic-Provokation.

Verstöße bitte per E-Mail an die im [Impressum](docs/RECHTLICHES.md) genannte
Adresse melden. Beiträge, die gegen diesen Kodex verstoßen, können ohne weitere
Begründung entfernt werden.

Dieser Kodex lehnt sich an den [Contributor Covenant](https://www.contributor-covenant.org) an.
